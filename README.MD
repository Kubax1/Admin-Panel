# Admin Panel

A modern admin panel application built with React on the frontend and Spring Boot on the backend.  
The project is designed as a reusable base for managing data, content, contact messages, users, and application settings.

## Tech Stack

### Frontend
- React
- TypeScript
- Mantine UI
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Gradle

### DevOps
- Docker
- Docker Compose

## Features

- Dashboard with charts and statistics
- Contact messages management
- Content management structure
- Application settings section
- PostgreSQL database
- Database migrations with Flyway
- REST API backend
- Modern UI with Mantine
- Local development setup with Docker
